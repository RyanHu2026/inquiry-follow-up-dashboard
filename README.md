# CRM 客户管理系统

一个面向外贸业务场景的中文 CRM 客户信息管理系统，使用原生 HTML、CSS 和 JavaScript 制作。

## 项目定位

这是一个可操作的客户管理原型，用于统一管理客户、询盘、报价和跟进进度。

## 当前功能

- 左侧导航以“数据概览”为首项，并可切换工作台、询盘管理、高意向客户、跟进日历和设置
- 数据概览首页展示客户国家分布世界地图和国家客户数量
- 新增、编辑、删除客户询盘
- 记录联系人姓名、职位、电话、邮箱、WhatsApp、LinkedIn/其他联系方式
- 记录首选联系渠道
- 一键导出客户联系方式交接表 CSV
- 记录客户来源：阿里国际站、RFQ、独立站、LinkedIn、展会等
- 多选产品兴趣偏好：柔性石材、MCM、外墙、室内、弧形墙面、样品
- 直接修改跟进状态和优先级
- 支持状态：新询盘、跟进中、等待回复、已报价、已成交
- 询盘管理列表按最近跟进日期从新到旧排列
- 客户详情侧滑面板
- 客户详情展示客户来源、产品兴趣偏好、报价信息、下一步行动和跟进时间线
- 支持报价日期、报价金额、币种和报价有效期
- 支持下次跟进日期和下一步行动
- 自动识别逾期跟进
- 真实月份跟进日历
- 日历优先按下次跟进日期排程，没有下次日期时兼容显示最近跟进日期
- 同一天显示全部客户记录，不覆盖、不轮换
- 点击客户名称或日历记录可打开详情
- 上个月、下个月和回到今天
- 搜索买家、国家、联系人、联系方式、产品和备注
- 点击地图国家或国家列表可跳转询盘管理并按国家筛选
- 按状态筛选
- 高意向客户自动汇总
- 待办事项按下次跟进日期生成
- 数据概览根据当前记录动态计算
- 数据概览作为首个首页入口
- 真实世界国家边界地图
- 世界地图路径和 D3 渲染依赖已内嵌到 `index.html`，单独打开网页文件也能加载
- 客户地点会先标准化为国家，支持国家名、英文名、ISO 代码、城市、省州和地区名
- 例如 Cape Town / 开普敦 / Western Cape / Cape Town, South Africa 会归入南非
- 例如 广东 / Guangdong / California / Ontario / Catalonia 会归入对应国家
- 客户所在国家自动点亮
- 地图圆点显示国家客户数量
- 点击国家或地图点位跳转到询盘管理并筛选该国家
- 国家列表按标准化后的国家名称统计
- 地图边界来源：DataHub geo-countries（国家多边形数据）
- 导出 CSV
- 恢复初始数据和清空客户数据
- 浏览器保存修改
- 手机端导航和布局适配

## 本地运行

直接用浏览器打开 `index.html` 即可，不需要安装依赖，也不需要构建项目。

## 操作说明

1. 点击左侧导航切换管理页面。
2. 在“询盘管理”中新增或编辑客户记录。
3. 直接调整优先级和跟进状态，列表会重新按最近跟进日期排序。
4. 打开“跟进日历”，同一天的所有客户记录会显示在同一个日期格中。
5. 点击日历中的记录可以直接打开编辑窗口。
6. 在“设置”中可以恢复初始数据或清空客户数据。
7. 点击“导出数据”可以下载当前客户 CSV 文件。

## 数据说明

当前版本使用浏览器存储保存客户记录，适合原型体验和功能测试。正式业务使用还需要增加登录、权限、服务端数据库、备份和安全审计。
